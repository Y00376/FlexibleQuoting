Derived curves

Each curve publishes one output curve to MDH. Formulas are stored as data, so a new curve needs no deployment.

In the real build the .NET engine calculates on the server, for previews and end-of-day runs alike. This mock-up calculates in the browser with sample data.

Quoting groups

One quoting page per group. Front office quotes the groups it is granted; market risk maintains its own groups. A value stays in force until someone changes it. Every change is audited.

Constants

Fixed numbers formulas use with CONST(). Market risk maintains them. A change adds a new version from the next run; earlier runs keep the old value. Every change is audited.
